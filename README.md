# Proyecto N-Capas: Plataforma de Cursos en Línea

Para poder trabajar con variables de entorno:
1. Crear un archivo `.env`. Usar el archivo `.env.example` como base.
2. En la configuración de ejecución de la CursoappAplication, agregar variables de entorno.
3. En vez de llenar la tabla manualmente, colocar que las variables de entorno las obtenga del archivo `.env`.
4. ¡Y eso sería todo!
